# 🥚 무한의 계란 (Infinite Egg)

> '무한의 계단' 모티브의 내리막길 굴러가기 아케이드 게임!  
> 현재 **순수 와이어프레임 스켈레톤 & 모바일/PC 양방향 UI 레이아웃 에디터** 구조로 운영되며, PC뿐만 아니라 스마트폰에서도 직접 실행·플레이·UI 배치를 수정하고 결과를 코드베이스에 바로 반영할 수 있습니다.

---

## 📱 다운로드 및 실행 방법 (모바일 / PC 공용)

이 게임은 웹 서버나 추가 설치 없이 동작하는 **단일 HTML 파일(`infinite-egg.html`)** 로 배포됩니다.

1. **[Releases 페이지](https://github.com/slalglel3/infinite-egg/releases/latest)** 에서 최신 `infinite-egg.html` 파일을 다운로드합니다.
2. **PC**: 다운로드한 `infinite-egg.html` 을 크롬/엣지/사파리 등으로 열면 즉시 실행됩니다.
3. **모바일 (Android / iOS)**:
   - 다운로드한 `infinite-egg.html` 을 크롬/사파리 또는 파일 앱(`HTML 뷰어`가 아닌 **웹 브라우저로 열기** 권장)으로 실행합니다.
   - `360px ~ 430px` 등 어떤 모바일 화면 폭에서도 `390px` 논리 좌표계 비율이 자동 보정되어 잘림 없이 화면에 꽉 차게 표시됩니다.

## ✏️ 모바일 & PC UI 레이아웃 에디터 사용법

### 📱 모바일 환경
- 홈 화면 상단 툴바에서 **`[UI 편집]`** 버튼을 누르면 즉시 편집 모드가 활성화됩니다.
- **터치 이동 / 크기 조절**: 요소를 손가락으로 드래그하여 이동하고, 파란 8방향 핸들로 크기를 조절합니다. (빈 배경을 드래그하면 세로 스크롤)
- **실행 취소 / 다시 실행 (Undo / Redo)**: 상단 바 **`[↩]` / `[↪]`** 버튼으로 드래그, 크기 조절, 요소 추가·삭제, 순서 변경, 속성 편집을 자유롭게 되돌릴 수 있습니다.
- **하단 선택 퀵 바**: 요소를 선택하면 하단 탭바 위에 **`[요소명 · 속성]` `[↑]` `[↓]` `[복제]` `[삭제]`** 바가 나타나 이름·설명·X/Y/W/H(`±4px` 미세 버튼)·앞뒤 순서를 즉시 수정할 수 있습니다.
- **`[레이어+]`**: 새 와이어프레임 요소 추가 및 탭 전체 Z-order 관리.
- **`[완료]` / `[플레이]`**: 언제든 미리보기 전환 및 실제 게임 주행 테스트 가능.

### 🖥️ PC 환경 (`840px` 이상 넓은 화면)
- 중앙 `390px` 모바일 프레임을 중심으로 **좌측(레이어/추가/실행취소·다시실행/미리보기/스냅/플레이)** · **우측(이름/설명/형태/좌표/순서/내보내기)** 3단 에디터가 즉시 활성화됩니다. (`Ctrl+Z` / `Ctrl+Y` / `Ctrl+Shift+Z`, 방향키 미세 이동, `Delete` 지원)

## 🔄 수정한 UI를 AI 에이전트(AGY)에게 반영시키는 방법

다운로드한 `infinite-egg.html`을 모바일 또는 PC에서 직접 수정한 뒤, 다음 절차로 원본 소스에 오차 없이 반영할 수 있습니다.

1. **앱에서 반영 패키지 내보내기**
   - **모바일**: 상단 바의 **`[반영(N)]`** (또는 `[AGY 반영]`) 버튼 클릭
   - **PC**: 우측 패널 하단의 **`[AGY 반영 · 파일 내보내기/불러오기]`** 버튼 클릭
   - 앱이 기본 레이아웃 대비 변경 내역(추가/수정/삭제 Diff)을 자동 요약하고 `infinite-egg-layout-v1` JSON을 패키징합니다.
2. **전달 수단 선택 (환경에 맞게 선택)**
   - **`[AI 반영 요청 복사]`**: 변경 요약 + JSON 블록을 클립보드에 한 번에 복사합니다 (`file://` 환경 폴백 및 수동 복사창 지원). AGY 대화창에 그대로 붙여넣어 주세요.
   - **`[모바일 공유하기]`**: OS 공유 시트를 통해 메신저·메모·슬랙·이메일 등으로 바로 전송합니다.
   - **`[JSON 파일 저장]`**: `infinite-egg-layout-YYYYMMDD-HHmm.json` 파일을 내려받아 전달합니다.
   - *(이어 편집)* **`[불러오기]`** 탭에서 `.json` 파일이나 복사해 둔 텍스트를 다시 불러와 이어서 수정할 수 있습니다.
3. **소스코드 자동 반영 & 재배포 (AGY 실행)**
   - 전달받은 텍스트 또는 JSON 파일을 아래 명령으로 `src/data/defaultHomeLayouts.ts`에 즉시 적용한 뒤 재빌드 및 새 릴리즈로 배포합니다:
     ```bash
     # 파일로 적용
     npm run apply-layout -- path/to/infinite-egg-layout.json

     # 복사한 전체 메시지(stdin)로 적용
     npm run apply-layout -- --stdin < pasted-message.txt
     ```

## 🕹️ 인게임 조작법 및 핵심 시스템

* **기본 이동:** 중력에 의해 계란이 지그재그 경사로를 자동으로 굴러 내려갑니다.
* **[점프] (`Space` / `↑` / 우측 버튼):** 끊어진 길(GAP)을 포물선 점프로 넘습니다. 끝자락에서 점프하면 **PERFECT! (충격 0)**, 헛점프나 높은 낙폭 착지 시 내구도가 감소합니다.
* **[방향 전환] (`Z` / `X` / `←` / `→` / 좌측 버튼):** 코너 끝에서 정확히 방향을 전환합니다.
* **와이어프레임 5대 탭 (컨셉 이미지 기반 개별 에셋·백플레이트/버튼 상태 분리):** `1. 상점` · `2. 스킨` · `3. 홈` · `4. 미션 (일일·주간·월간·누적)` · `5. 도전`
* **100% 오프라인 사운드:** Web Audio API 기반 실시간 합성 사운드.
