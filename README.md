# 🥚 무한의 계란 (Infinite Egg)

> '무한의 계단' 모티브의 내리막길 굴러가기 아케이드 게임!  
> 중력으로 데굴데굴 굴러가는 달걀을 조작하여, 깨지지 않고 가장 깊은 곳까지 도달하세요!

---

## 🎮 다운로드 및 즉시 실행 방법

이 게임은 **완전한 단일 파일(Standalone Single-file HTML)**로 제작되었습니다.  
웹 서버나 인터넷 연결, 추가 설치가 전혀 필요 없습니다.

1. 저장소의 **[`infinite-egg.html`](./infinite-egg.html)** 파일을 다운로드합니다.
2. PC나 스마트폰 브라우저(크롬, 사파리, 엣지 등)에서 **더블 클릭(열기)**만 하면 즉시 게임이 실행됩니다!

---

## 🕹️ 조작법 및 게임 규칙

* **기본 이동:** 중력에 의해 계란이 자동으로 경사로를 데굴데굴 굴러 내려갑니다.
* **[점프] 버튼 (스페이스바 / ↑ 키):**
  * 중간중간 끊어진 길(GAP)을 포물선 점프로 뛰어넘습니다.
  * **판정:** 윗길 끝자락에서 정밀하게 점프하면 **충격 0 (PERFECT!)**, 너무 일찍 점프하면 높은 곳에서 떨어져 착지 낙폭 차이만큼 **내구도가 감소**합니다.
  * **헛점프 페널티:** 일반 길에서 불필요하게 점프하면 착지 충격으로 큰 내구도 감소가 발생합니다.
* **[방향 전환] 버튼 (Z / X / ← / → 키):**
  * 코너 끝에 정확히 도달했을 때 누르면 부드럽게 회전(**PERFECT TURN!**).
  * 코너에 도달하기 전에 너무 일찍 누르면 윗길에서 즉시 방향을 틀며 아랫길로 수직 낙하(드롭)하여, **떨어진 높이차만큼 쿵! 내구도가 감소**합니다.
  * 코너를 지나칠 때까지 누르지 않으면 절벽 밖 허공으로 추락합니다.

## 🌟 핵심 시스템

1. **4단계 실시간 계란 균열 (Crack System):**
   * 내구도가 줄어들수록 달걀 껍질에 실금 -> 균열 -> 심각한 파손(노른자 깜빡임)이 실시간으로 쩍쩍 갈라집니다.
   * 내구도가 0이 되면 착지 순간 **파삭-! 와장창** 12조각으로 산산조각 나는 물리 폭발 연출!
2. **반창고 아이템:**
   * 길 중간에 놓인 반창고를 먹으면 깨진 껍질이 치료(+20 HP)됩니다.
3. **유저 레벨 & 누적 경험치:**
   * 하강한 높이 1m당 1 EXP를 획득하며, 게임을 오래 플레이할수록 레벨이 오르고 내구도가 미세하게 단단해집니다.
4. **100% 오프라인 사운드 신디사이저:**
   * Web Audio API를 이용해 점프, 착지 충격, 껍질 틱, 깨짐 소리 등을 0ms 딜레이로 실시간 합성합니다.
